## What an agent can and cannot do here

RRD has **no public developer program**. There is no anonymously readable API
reference, no OpenAPI/Swagger/AsyncAPI/GraphQL contract, no SDK on any public
package registry, no MCP server and no A2A agent card. Do not attempt to
construct RRD API calls — nothing published states an endpoint, a payload or a
base URL.

RRD does operate customer-facing APIs, but they are reachable only by contracted
customers:

- RRD's own help page "RR Donnelley API" (https://intl.rrd.com/Help) states that
  RRD customer-facing APIs require a `Username` and an `APIKey` in the request
  header. That host resolves but refuses TCP 443 from the public internet.
- `api.rrd.com` resolves to 162.27.32.131 with ports 443 and 80 closed/filtered.
- ConnectOne (https://connectone.rrd.com/) is a customer storefront and returns
  HTTP 401 on every path, including `/.well-known/*`.

Access is obtained through an RRD account team, not through self-service signup.
